CH01

Videobeaux

streaming

Videobeaux is a locally running video-processing toolkit for artists. Build multi-effect pipelines in its node-based editor or automate them from the command line; its collection spans glitch, compositing, temporal effects, captioning, and editing.

  • Node-based editing and a scriptable CLI
  • Effects, compositing, and batch processing
  • Local-first creative video workflows

CH02

AdSlicer

on air

AdSlicer helps archivists clean up VHS captures and recorded television by detecting potential commercial breaks and splitting the recording into program and advertisement segments. It is designed to reduce repetitive manual editing while retaining useful archival information.

  • Commercial-break detection and splitting
  • Separate program and advertisement outputs
  • Metadata for archival and review
videoarchivingediting▶ VIEW PROJECT
CH03

drop-zone-ops

on air

Drop Zone Ops is a browser-based M3U playlist builder for independent broadcasters. Drop in local files, folders, or media URLs; arrange the order, label commercials and bumpers, and export a playlist for VLC or OBS.

  • Drag-and-drop playlist assembly
  • Local paths and remote media URLs
  • M3U export with broadcast-oriented tags
broadcastplaylistsbrowser▶ VIEW PROJECT
CH04

huff

on air

huff is a real-time video-glitch and datamoshing application for live visual performance. Feed it a camera or video file, manipulate feedback, warps, scanlines, and other distortions, and route the results to a separate output window.

  • Real-time video and camera processing
  • Datamosh, feedback, trails, and warps
  • Live performance and output workflows
videoglitchrealtime▶ VIEW PROJECT
CH05

Raspi Composite Player

on air

A straightforward media player built for the Raspberry Pi 3 Model B+ and its analog composite video output. The project explores playing digital media through older display hardware, particularly CRT-style video setups.

  • Raspberry Pi media playback
  • Analog composite video output
  • Retro-display experimentation
raspberry picompositevideo▶ VIEW PROJECT
CH06

mastacraf

on air

mastacraf is a Rust command-line audio-mastering workflow powered by FFmpeg. Analyze a track, apply preset-driven loudness and peak targets, and generate reports with before-and-after audio measurements and visuals.

  • Audio analysis and mastering presets
  • Loudness and true-peak control
  • JSON reports, waveforms, and spectrograms
audiomasteringrust▶ VIEW PROJECT
CH07

VideoSampler10_VS10

on air

VideoSampler10 (VS10) is a compact browser-based video sampler. Load local video, slice moments into a set of playable pads, and perform with clips through a simple hands-on interface.

  • Local-video sampling
  • Playable clip pads
  • Lightweight browser workflow
videosamplerbrowser▶ VIEW PROJECT
CH08

Webglo

glowing

Webglo (WebGL Ordinals) explores video art that can live outside a conventional platform. Small HTML, JavaScript, and WebGL works are published using Bitcoin Ordinals so the artwork can be shared and rendered in a browser as a decentralized digital object.

  • Browser-rendered video and generative art
  • Single-file web artwork experiments
  • Bitcoin Ordinals publishing
webbitcoinvideo art▶ VIEW PROJECT

TURRRBO

on air

TURRRBO is a desktop image-generation experiment built around pretrained StyleGAN2 models. It explores navigating a model’s latent space to produce and discover unusual synthesized imagery.

  • Pretrained StyleGAN2 image models
  • Latent-space exploration
  • Desktop-oriented creative experimentation
generativeimagesai▶ VIEW PROJECT

junkpile

on air

junkpile is a growing assortment of code templates for live visual art. It collects reusable starting points and experiments for artists who would rather adapt a working sketch than build every visual system from scratch.

  • Reusable creative-code templates
  • Live visual art experiments
  • Starting points for new work
visual artcodetemplates▶ VIEW PROJECT

Illogica Factory

smokin'

Illogica Factory is an experiment in automated AI cannibalism: an intentionally strange environment for testing creative automation and what happens when generative systems feed back into themselves. Part playground, part research workshop.

  • Generative feedback experiments
  • Creative automation workflows
  • Exploratory interface and system design

obs-relay

on air

obs-relay is a remote-control and automation project for OBS Studio. It explores the OBS control API and helps run media playlists, including event-driven progression from one video to the next during a broadcast.

  • OBS control and API exploration
  • M3U-based media playlists
  • Event-driven playlist advancement
obsbroadcastautomation▶ VIEW PROJECT

observing

Viewfinder is a proposed unified API for EVM blockchain explorers. Its goal is to reduce the need to implement a different integration for every explorer by putting common queries behind a consistent interface.

ratelimiting

listening
